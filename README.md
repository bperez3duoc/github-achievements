# GitHub Achievements Sandbox 🏆

Repositorio público para experimentar con GitHub Actions, pull requests y desbloquear insignias oficiales de GitHub.

### Insignias Activas:
- ⚡ **Quickdraw**: Issue creado y cerrado en menos de 5 minutos.
- 🚀 **YOLO**: Pull request fusionada sin revisión.
- 👯 **Pair Extraordinaire**: Commit con co-autoría en una Pull Request fusionada.
- 🦈 **Pull Shark**: Pull requests fusionadas.
